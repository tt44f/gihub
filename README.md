# Number Sign — Python & Jenkins

Petit projet Python permettant de déterminer le signe d'un nombre.

## Fonctionnement

Le programme prend un nombre en argument et affiche :

- `Positive number` si le nombre est positif
- `Negative number` si le nombre est négatif
- `Zero` si le nombre est égal à zéro

## Tests automatisés

Un `Jenkinsfile` permet d'automatiser l'exécution de plusieurs cas de test :

- `5`
- `-3`
- `0`

Les tests permettent de vérifier les trois résultats possibles du programme.

## Technologies utilisées

- Python
- Jenkins
- Git

## Objectif

Ce projet m'a permis de pratiquer :

- l'utilisation de Python avec des arguments en ligne de commande ;
- l'écriture d'un pipeline Jenkins simple ;
- l'automatisation de l'exécution de tests ;
- l'utilisation de GitHub pour versionner et documenter un projet.
